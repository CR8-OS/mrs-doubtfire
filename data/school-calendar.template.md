# School calendar

One file per school. Ingest the published calendar into these tables so the
dates can be computed against, not read from a PDF every time.

| | |
|---|---|
| School | |
| Child | |
| Source | where the calendar came from |
| Ingested | YYYY-MM-DD |
| Covers | term or school year |

Re-ingest whenever the school publishes an update. A calendar more than a term
old is not usable.
